# rs-spi 0.4 Downstream Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement task-by-task.

**Goal:** Migrate qubit-fs, qubit-mime, and qubit-magika from qubit-spi 0.3 to the local relative-path 0.4 API.

**Architecture:** Each crate depends directly on ../rs-spi with version "0.4". Filesystem uses one immutable registry and named resolution. MIME converts both provider domains to Arc outputs and immutable built-in registries. Magika becomes a MIME registration contributor.

**Tech Stack:** Rust 2024, Rust 1.94, local Cargo path dependencies.

## Global Constraints

- Preserve pre-existing Cargo.lock, Cargo.toml version, and README changes in every downstream worktree.
- Set qubit-spi as { path = "../rs-spi", version = "0.4" }; do not use a patch version.
- Do not commit, because the user did not request downstream commits.
- Remove no unrelated code; only remove APIs made obsolete by SPI 0.4.
- Every behavioral migration starts with a failing focused test and ends with the affected crate test suite.
