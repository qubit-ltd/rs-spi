# rs-spi 0.8 API Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release `qubit-spi` 0.8 with invariant-owned selector errors, decisive standard error chaining, explicit string ownership, current public documentation, and migrated direct workspace consumers.

**Architecture:** Public error enums remain directly matchable, while variant-level `#[non_exhaustive]` reserves construction to `qubit-spi`. `ProviderSelectorError` becomes the sole owner of rejected selector input, and higher error layers retain only location plus source. Each independent repository is migrated, verified, and committed separately.

**Tech Stack:** Rust 2024, `thiserror` 2, Cargo integration tests and doctests, repository `align-ci.sh` and `ci-check.sh` workflows.

## Global Constraints

- Breaking public API changes are authorized and require `qubit-spi` version `0.8.0`.
- Keep `ProviderErrorKind`, `ProviderSelectionKind`, and `ResolutionTermination`.
- Do not add selector lookup optimization without benchmark evidence.
- Do not add output-only resolver method families.
- Do not reintroduce parallel Kind types or variant-specific optional accessors.
- Preserve the existing uncommitted `num-rational` changes in `rs-fs/Cargo.lock`; never stage them in this task's commit.
- Use English Conventional Commit messages and keep commits repository-local.
- Do not push.

```rust
/// Verifies a policy-stopping failure remains the standard aggregate source
/// after an earlier fallback-eligible failure.
#[test]
fn test_policy_stop_after_fallback_exposes_its_decisive_source() {
    let mut builder = ProviderRegistry::<GreetingSpec>::builder();
    for (id, priority, error) in [
        (
            "remote",
            20,
            ProviderError::unavailable("remote backend is absent"),
        ),
        (
            "broken",
            10,
            ProviderError::initialization_failed("backend startup failed"),
        ),
    ] {
        builder
            .register(
                ProviderDescriptor::new(
                    ProviderId::new(id).expect("test provider ID should be valid"),
                )
                .with_priority(priority),
                TestProvider(Err(error)),
            )
            .expect("test provider should register");
    }

    let result = ProviderResolver::new(
        builder.build(),
        FallbackPolicy::OnAbsence,
    )
    .create_auto(&());
    let error = match result {
        Ok(_) => panic!("initialization failure should stop resolution"),
        Err(error) => error,
    };

    assert_eq!(2, error.attempts().len());
    assert_eq!(
        Some(ResolutionTermination::StoppedByPolicy),
        error.termination(),
    );
    let decisive = error
        .decisive_attempt()
        .expect("policy stop should have a decisive attempt");
    let source = Error::source(&error)
        .and_then(|source| source.downcast_ref::<AttemptFailure>())
        .expect("decisive attempt should be the aggregate source");
    assert!(std::ptr::eq(decisive, source));
}
```

```rust
impl Error for ResolutionError {
    /// Returns the direct cause when the failure has one unambiguous source.
    ///
    /// # Returns
    ///
    /// The selector parse source for invalid input, the decisive failed attempt
    /// for an aggregate, or `None` otherwise.
    #[inline]
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        match self {
            Self::InvalidSelector { source, .. } => Some(source),
            Self::NoProviderSucceeded { .. } => self
                .decisive_attempt()
                .map(|attempt| attempt as &(dyn Error + 'static)),
            Self::EmptySelection
            | Self::UnknownProvider { .. }
            | Self::EmptyRegistry => None,
        }
    }
}
```

```rust
use std::{
    error::Error,
    fmt,
};

#[derive(Clone, Debug, Eq, PartialEq)]
#[non_exhaustive]
pub enum ProviderSelectionError {
    /// One selector input cannot be parsed.
    InvalidSelector {
        /// Zero-based chain position, or `None` for a named selector.
        selector_index: Option<usize>,
        /// Selector parsing failure retaining the verbatim input.
        source: ProviderSelectorError,
    },
    /// A chained selection contains no selector inputs.
    EmptyChain,
}

impl fmt::Display for ProviderSelectionError {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::InvalidSelector {
                selector_index: Some(index),
                source,
            } => write!(
                formatter,
                "invalid provider selector at selection index {index}: {:?}",
                source.input(),
            ),
            Self::InvalidSelector {
                selector_index: None,
                source,
            } => write!(
                formatter,
                "invalid provider selector {:?}",
                source.input(),
            ),
            Self::EmptyChain => formatter
                .write_str("provider selection chain must not be empty"),
        }
    }
}

impl Error for ProviderSelectionError {
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        match self {
            Self::InvalidSelector { source, .. } => Some(source),
            Self::EmptyChain => None,
        }
    }
}
```
