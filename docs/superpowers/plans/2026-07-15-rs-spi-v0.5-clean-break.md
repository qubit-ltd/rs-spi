# rs-spi 0.5 Clean-Break Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `qubit-spi` 0.5 with truthful construction boundaries,
single-build registry indexes, owned provider failures, rule-compliant source
and test organization, and corrected direct downstream integrations.

**Architecture:** Preserve the synchronous immutable registry/resolver design.
Move public types into one file each, private storage and representation enums
under `src/internal/`, and keep useful public paths through crate-root
re-exports. Intentionally remove public fabrication constructors and update all
workspace consumers without compatibility shims.

**Tech Stack:** Rust 2024, Rust 1.94, Cargo integration tests, `thiserror` 2,
repository `align-ci.sh`/`ci-check.sh` tooling.

## Global Constraints

- Do not add async construction, discovery, global registries, macros, or new
  fallback policies.
- Use TDD for the MIME bug and every new behavior; preserve existing tests as
  characterization coverage before structural refactoring.
- Keep every struct, enum, and trait in its own snake-case file; put private
  types one per file under `src/internal/`.
- Keep root-level public type names unless this plan explicitly restricts a
  constructor.
- Use the canonical Rust copyright header and complete English Rustdoc.
- Do not stage, commit, push, reset, or discard user changes.
- Preserve the pre-existing `rs-mime/Cargo.lock` dependency-feature cleanup.
